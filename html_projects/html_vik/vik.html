Visual Immersion Kit - vik

vik is a collection of C++ libraries developed to facilitate the implementation of proof-of-concept projects in computer vision, computer graphics, machine learning algorithms, and deep learning models. The primary goal at its inception was to design a flexible and extensible software architecture that integrates solutions from various disciplines while operating transparently across a broad range of hardware platforms.

A brief overview of its constituent libraries is provided below. If you are interested, please request access by email.

It supports distributed and networked execution, enabling command-driven simulations and client–server configurations. This allows components to operate across system boundaries while maintaining a coherent execution model.

Extensibility is achieved through a plugin-based architecture, allowing new functionality—such as learning modules, custom processing pipelines, or domain-specific logic—to be integrated without modifying the core system. The framework provides flexible interaction mechanisms through pluggable control systems, enabling diverse input and control strategies tailored to specific applications.

A core component is its support for offline rendering via CPU-based ray tracing, facilitating high-quality, physically-based image generation as well as a real time interactive ray tracing. The system is designed to integrate with advanced rendering techniques and to interface naturally with vision and learning pipelines.

In addition, the framework targets applications in 3D reconstruction, structure-from-motion, and radiance field representations, positioning it as a foundation for research and development at the intersection of computer graphics and machine learning.
